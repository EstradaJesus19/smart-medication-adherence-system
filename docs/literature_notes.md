# Related-work research worksheet

The literature review has not yet been conducted. This file is a collection plan,
not evidence for claims about adherence improvement or device effectiveness.

## Questions

1. Which systems only remind, which record access, and which dispense medication?
2. What observable evidence is used: lid motion, compartment presence, weight,
   user acknowledgement or another measurement?
3. How are missed and incorrect interactions defined and evaluated?
4. What usability evidence is available for the target population?
5. How are power loss, connectivity failures and privacy handled?

Search university library databases and primary papers with combinations of
“electronic medication event monitoring”, “instrumented pill organizer”,
“smart pillbox reed switch”, and “pill removal weight sensor”. Include comparable
commercial product manuals where useful, clearly separated from evaluated studies.
